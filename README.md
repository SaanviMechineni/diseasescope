# diseasescope
DiseaseScope: a Streamlit dashboard analysing incidence of Dengue, Malaria, ADD, Measles and H1N1 across 36 Indian states (2019–2024). Features pandas EDA, population-weighted rates, India maps, K-Means clustering, forecasting, Isolation Forest anomalies and a public health advisory. Dengue is real data; other diseases are simulated.
